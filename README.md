### About

I build software that runs on your machine, not mine. The current focus is the document-to-AI pipeline: clean text extraction, structured post-processing, and retrieval surfaces (REST, MCP, OpenAI-compatible) for both humans and agents. One Docker container, any vision model, any vector store, your data.

Open to collaborating on open-source tools that respect privacy and work offline.
